# TTMs_try

* read papers of [TTMs](https://arxiv.org/pdf/2401.03955), [PatchTSMixer](https://arxiv.org/pdf/2306.09364), [PatchTST](https://arxiv.org/pdf/2211.14730)
* summarize the constracture of these models
* try [tutorials](https://github.com/ibm-granite/granite-tsfm/blob/main/notebooks/hfdemo/ttm_getting_started.ipynb) of TTMs, PatchTSMixer, PatchTST
* generate MGdata referring [the methods in matlab](https://www.mathworks.com/matlabcentral/fileexchange/24390-mackey-glass-time-series-generator)
* try ttms on MGdata (different percentage finetunning, different time delay)
* try Runge-Kutta method, Eular Method, and Runge-Kutta method combined with linear interpolation to generate MGdata
* run ttms on MGdata with different percentage finetunning, different way to collect train samples, and different x0, time delay when generating MGdata.
